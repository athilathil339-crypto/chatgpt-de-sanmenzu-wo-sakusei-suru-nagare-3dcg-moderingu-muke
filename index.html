STEP 02

ChatGPTへ画像をアップロード

ChatGPTの画像機能に、
三面図にしたい写真を入れます。

斜め写真1枚だけの場合、見えない面はAIが推測します。正面・横・斜めの複数画像があると精度が上がります。

  • 画像を添付
  • 用途を伝える
  • 出力サイズを指定
  • ビューの順番を指定
STEP 03

三面図生成プロンプトを入力

添付画像のオブジェクトを解析し、 3DCGモデリング用イメージプレーンとして使用可能な 三面図画像を生成してください。 出力画像サイズは必ず：横 1024px、縦 3072px。 画像は縦に3分割し、以下の順番で配置してください。 上段：正面図 front view 中段：側面図 side view 下段：上面図 top view 各エリアのサイズは必ず 1024px × 1024px。 各1024x1024エリアの外周を、1ピクセル幅の黒い線で囲んでください。 各ビューは同じオブジェクトを、同じスケール・同じ比率・同じ中心位置で配置してください。 All views must describe the exact same object with identical proportions. 正投影 orthographic projection で生成してください。パースは除去してください。 元画像の材質・色・ディテールを維持してください。 白背景。文字・ラベル・寸法線は不要。

STEP 06

スケールと中心を確認する

確認ポイント

  • 高さが同じか
  • 中心軸が揃っているか
  • 横幅・奥行きが不自然でないか
  • ビューごとに別物になっていないか

プロンプトで効く言葉

  • same scale across all views
  • consistent proportions
  • center aligned
  • orthographic projection
CAUTION

AI三面図の注意点

  • 完全なCAD図面ではない
  • 見えない面は推測になる
  • 細部がビューごとに変わることがある
  • 一度で完璧に揃わない場合がある

だから、モデリング前に
形状・比率・中心軸を必ずチェックします。
